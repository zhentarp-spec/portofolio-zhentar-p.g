Cerita Saya

Saya belajar membuat web di rumah dan di sekolah. Saya masuk jurusan RPL (Rekayasa Perangkat Lunak) — jurusan yang awalnya bukan pilihan saya.

Awalnya saya tidak mau masuk RPL, karena saat daftar sekolah saya memilih jurusan lain. Ternyata takdir berkata lain — saya dipilih untuk masuk RPL. Awalnya tidak semangat karena bukan pilihan saya, tapi makin ke sini saya jadi suka. Ternyata ngoding itu asik, dan saya makin suka membuat web!

Sekarang saya sedang mendalami HTML, CSS, JavaScript, Python, dan PHP. Setiap hari saya belajar hal baru, walau kadang susah. Tapi saya percaya, kalau terus latihan, saya bisa jadi web developer yang hebat.
